# Pokémon Chess

Шахматы для iPad с покемонами, игрой против компьютера и выбором своей команды. Профиль тренера, статистика и текущая партия сохраняются в браузере.

## Локальный запуск

Из корня репозитория выполните `python3 -m http.server 8000 --directory dist`, затем откройте [игру](http://localhost:8000).

Статические файлы приложения находятся в `dist/`. Сборка не требуется.
